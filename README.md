# منصة ريادة (ربط أصحاب المشاريع بالمستثمرين)

هذا المشروع عبارة عن تطبيق ويب كامل (Full-Stack) باستخدام React في الواجهة الأمامية و Node.js/Express في الواجهة الخلفية.

## الهدف من التطبيق
توفير منصة تتيح لأصحاب المشاريع الناشئة (Founders) والمستثمرين (Investors) التسجيل والتواصل. يمكن لأصحاب المشاريع عرض مشاريعهم والمبالغ المطلوبة للتمويل، ويمكنهم أيضاً رؤية قائمة بالمستثمرين واهتماماتهم. بالمقابل، يمكن للمستثمرين استعراض المشاريع المتاحة للاستثمار.

## هيكل الملفات
- **backend/**: يحتوي على كود الواجهة الخلفية (Node.js + Express).
  - `server.js`: الخادم الأساسي والـ API (مصمم باستخدام مصفوفات في الذاكرة لتسهيل التشغيل بدون إعدادات قاعدة بيانات).
  - `package.json`: تفاصيل حزم الـ backend.
- **frontend/**: يحتوي على كود الواجهة الأمامية (React + Vite).
  - `src/App.jsx`: يحتوي على مكونات النظام كاملة مثل (تسجيل الدخول، التسجيل، لوحة تحكم المؤسس، لوحة تحكم المستثمر).
  - `src/index.css`: التنسيقات (Styling).
  - `index.html`: الصفحة الرئيسية للتطبيق.

## كيفية تشغيل المشروع

1. **تشغيل الخادم (Backend):**
   ```bash
   cd backend
   npm install
   npm start
   ```
   *سيعمل الخادم على المنفذ 5000.*

2. **تشغيل الواجهة الأمامية (Frontend):**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   *ستعمل الواجهة الأمامية عادةً على المنفذ 5173.*

## الميزات
- نظام تسجيل دخول وتسجيل حساب جديد (Role-Based).
- **حساب مؤسس:** يمكنه إضافة مشروع جديد، ورؤية المستثمرين المتاحين.
- **حساب مستثمر:** يمكنه استعراض جميع المشاريع المضافة والمبالغ المطلوبة لتمويلها.
